# Archivo Documental

Aplicacion MVC en PHP, MySQL y JavaScript para administrar documentos PDF en oficinas gubernamentales.

## Instalacion rapida

1. Crear la base de datos, tablas y usuario de aplicacion:
   `mysql -uroot < database/schema.sql`
2. Ajustar credenciales en `config/database.php` si es necesario.
3. Entrar desde el navegador:
   `http://localhost/archivo/`
